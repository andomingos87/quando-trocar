# Decisoes de arquitetura (ADRs)

As decisoes canonicas deste projeto vivem em **`docs/adr/`** (ADR-0001..ADR-0019, com indice em
`docs/adr/README.md`). Nao duplicar aqui.

Esta pasta existe como slot do fluxo Aurea (`/aurea-context:adr`). Ao registrar uma nova decisao,
mantenha o padrao existente: grave o ADR em `docs/adr/`, atualize `docs/adr/README.md` e
`docs/CONTEXT_CHANGELOG.md`. Se em algum momento o time decidir migrar os ADRs para ca, faca em
uma mudanca dedicada.
